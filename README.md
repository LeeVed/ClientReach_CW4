# Веб-Приложение ClientReach

ClientReach - это веб-приложение для управления email-рассылками с разграничением прав доступа для разных типов 
пользователей.Этот сервис управления рассылками позволяет пользователям управлять рассылками сообщений для клиентов. 
Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок, 
а также отправки сообщений по требованию.
  
# Установка

Клонирование репозитория

            git clone <repository-url>
            cd ClientReach_CW4

Создание виртуального окружения

    poetry install

Установка зависимостей 

    poetry add isort 
                flake8 
                black 
                isort
                mypy 
                django
                psycopg2-binary 
                python-dotenv 
                pillow 
                ipython 
                redis 

Настройка переменных окружения (создайте файл .env в корне проекта):

    Базовые настройки Django
    DEBUG=True
    SECRET_KEY=ваш-секретный-ключ
    ALLOWED_HOSTS=localhost,127.0.0.1
    
    Настройки базы данных (PostgreSQL)
    DB_ENGINE=django.db.backends.postgresql
    DB_NAME=clientreach_db
    DB_USER=postgres
    DB_PASSWORD=ваш-пароль
    DB_HOST=localhost
    DB_PORT=5432
    
    Настройки почты (для отправки рассылок)
    EMAIL_HOST=smtp.yandex.ru
    EMAIL_PORT=587
    EMAIL_HOST_USER=ваш-email@yandex.ru
    EMAIL_HOST_PASSWORD=ваш-пароль
    EMAIL_USE_TLS=True
    DEFAULT_FROM_EMAIL=ваш-email@yandex.ru
    
    Настройки кеширования (Redis)
    REDIS_URL=redis://localhost:6379/1
    CACHE_ENABLED=True

Настройка базы данных

    Применение миграций
    python manage.py migrate
    
    Создание суперпользователя
    python manage.py createsuperuser
    
    Создание групп пользователей
    python manage.py shell
    >>> from django.contrib.auth.models import Group
    >>> Group.objects.create(name='users')
    >>> Group.objects.create(name='managers')
    >>> exit()

Запуск сервера разработки

    python manage.py runserver

Откройте браузер и перейдите по адресу: http://localhost:8000


## Использование

Шаг 1: Регистрация и вход

Перейдите на главную страницу
Нажмите "Регистрация" в навигационной панели
Заполните форму (email и пароль)
Подтвердите email (если настроена отправка почты)
Войдите в систему

Шаг 2: Работа с клиентами (получателями)

В навигационной панели выберите "Получатели"
Нажмите "+ Добавить получателя"
Заполните форму:
Email (обязательно)
ФИО (опционально)
Комментарий (опционально)
Сохраните получателя
Для редактирования нажмите кнопку "Редактировать" рядом с нужным получателем
Для удаления нажмите кнопку "Удалить"

Шаг 3: Создание сообщений

В навигационной панели выберите "Сообщения"
Нажмите "+ Создать сообщение"
Заполните форму:
Тема письма (обязательно)
Текст письма (обязательно)
Сохраните сообщение

Шаг 4: Настройка рассылки

В навигационной панели выберите "Рассылки"
Нажмите "+ Создать рассылку"
Заполните форму:
Дата и время начала (когда рассылка должна начаться)
Дата и время окончания (когда рассылка должна завершиться)
Статус:
"Создана" - если планируете запустить позже
"Запущена" - если хотите запустить сразу
Сообщение - выберите из созданных сообщений
Получатели - выберите получателей (можно несколько)
Сохраните рассылку

Шаг 5: Запуск рассылки

Автоматический запуск:
Если статус "Запущена" и текущее время между датой начала и окончания
Рассылка автоматически готова к отправке
Ручной запуск:
Перейдите в детали рассылки
Если рассылка активна (статус "Запущена")
Нажмите кнопку "Отправить"
Система отправит письма всем выбранным получателям

Шаг 6: Мониторинг результатов

На главной странице смотрите общую статистику
В разделе "Статистика" - детальная информация по вашим рассылкам
В деталях рассылки - просмотр логов отправки:
Успешные отправки (зеленые бейджи)
Неудачные отправки (красные бейджи)
Ответы почтового сервера


Система автоматически обновляет статусы рассылок:
"Создана" → если текущая дата раньше даты начала
"Запущена" → если текущая дата между началом и окончанием
"Завершена" → если текущая дата позже даты окончания

Система безопасности
Каждый пользователь видит только свои данные
Менеджеры видят все, но не могут изменять
Суперпользователь имеет полный доступ
Пароли хранятся в зашифрованном виде
Сессии защищены

Логирование всех действий
Для каждой попытки отправки сохраняется:
Дата и время попытки
Статус (Успешно/Не успешно)
Ответ почтового сервера
Это позволяет отслеживать эффективность и диагностировать проблемы

Для менеджеров
Блокировка пользователей:
Войдите как менеджер
Перейдите в раздел "Пользователи"
Найдите нужного пользователя
Нажмите "Заблокировать" (или "Разблокировать" если уже заблокирован)
Отключение рассылок:
Перейдите в детали рассылки
Если рассылка активна (статус "Запущена")
Нажмите кнопку "Отключить рассылку"
Для включения нажмите "Включить рассылку"
